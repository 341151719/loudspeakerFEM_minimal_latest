# 扬声器 FEM sum rules 深入验证最终分析

## 结论等级

1. **通过：有限频窗内的被动性与功率分解。** 0.1 Hz–15 kHz 所有已算频点的 `Re Zmot` 和由远场功率扣除后的 `Rinternal` 均非负。321 点主扫描中最小值分别为 0.00199372 Ω 和 0.00199372 Ω。
2. **有限窗强支持：M2 低频权重预算。** 387 点合并积分在 1 Hz–15 kHz 得到 0.03690336 Ω·s，是实刚度矩阵端点 A0 = 0.03707604 Ω·s 的 99.534%。
3. **未闭合：M0 高频预算。** 自适应积分得到 20,324.73 Ω/s，只占质量矩阵端点 A∞ = 56,776.27 Ω/s 的 35.798%。缺少的 64.202% 不能解释为求和规则失效，但它表明 15 kHz 上限远不足以验证该全频等式。
4. **严格 M2 定理不适用于当前经验损耗外推。** 材料中的频率无关 loss factor 在 ω=0 复静态顺应中留下非零虚部，使 M2 在数学上有对数型低频发散。因此 99.534% 应称为工程频窗一致性，不应称为从 0 到无穷的严格证明。

## 固定模型与数值口径

- 全频段固定使用 `configs/sum_rules_highest_accuracy.json`，不启用生产扫频的 P1/P2 或网格自动路由。
- 结构网格：122,513 节点、244,862 个自由自由度；声学未知量：171,649；单频耦合规模约 416,511。
- 主扫描：1 Hz–15 kHz 的 321 点对数嵌套网格。
- 自适应扫描：对覆盖 99% 上一层局部积分差的 33 个区间增加 66 个四分点，与主网格合并为 387 点。
- 辐射功率以 1 m 半空间完整方向图积分为主值，Boundary 93 有符号通量只作交叉检查。

## 频率积分收敛

| 积分网格 | M0 (Ω/s) | M2 (Ω·s) |
|---|---:|---:|
| 81 点 | 20,530.38 | 0.03697334 |
| 161 点 | 19,540.90 | 0.03690693 |
| 321 点 | 20,303.56 | 0.03689047 |
| 321 + 66 自适应点 | 20,324.73 | 0.03690336 |

161→321 的 M0 变化为 3.756%，原因是 9–12 kHz 的少数窄模态；增加 66 个定向频点后，M0 相对 321 点只改变 0.1042%。相邻层局部差绝对值的后验总指标为 313.24 Ω/s，占自适应 M0 的 1.541%。这是保守的收敛指标，不是严格误差上界。

M0 在 15 kHz 内只回收 35.798% 因而已不能归因于频率积分太粗：自适应误差指标约 1.54%，而未回收预算为 64.20%。大量差额与 15 kHz 以上的高阶结构自由度和数值谱一致；但频率无关 loss factor 也破坏了严格 Herglotz 前提，因此不能把全部差额严格归因于物理高频谱权重。

## 效率预算的去向

| 有限窗预算 | M0 (Ω/s) | 占 M0 | M2 (Ω·s) | 占 M2 |
|---|---:|---:|---:|---:|
| 有用辐射效率项 `Rc·η/(1-η)` | 848.896 | 4.1767% | 0.0000680448 | 0.1844% |
| 内部损耗惩罚项 `Rinternal/(1-η)` | 19,475.833 | 95.8233% | 0.03683531 | 99.8156% |
| 合计 | 20,324.729 | 100% | 0.03690336 | 100% |

最高远场效率仅 0.6777%，出现在约 1.202 kHz。最大辐射电阻约 0.1228 Ω，出现在 52.80 Hz；此时运动电阻约 26.20 Ω，说明主共振的谱权重主要被结构/内部损耗消耗，而不是转化成有用远场辐射。

`odds` 恒等式的最大残差为 3.55×10⁻¹⁵ Ω。由于 `Rinternal` 和 `η` 由同一组功率量定义，这个结果证明后处理的代数一致性，不是独立的物理验证。

## 低频端点与经验损耗的影响

- 实刚度矩阵端点：A0 = 0.03707604 Ω·s。
- ω=0 的复刚度二次型：0.03707556 − 6.2375×10⁻⁶ i Ω·s。
- 因而渐近 `Re Zmot/ω = 6.2375×10⁻⁶ Ω·s`，M2 每向低频延伸一个十倍频程会增加约 9.143×10⁻⁶ Ω·s，即 A0 的 0.0247%。
- 1 Hz–15 kHz 的 M2 为 A0 的 99.534%；把 0.1–1 Hz 实算积分加入后变为 A0 的 100.042%。这种截止频率依赖正是严格低频积分不存在的数值表现。

要严格验证原文的 M2 Herglotz 等式，必须将频率无关 loss factor 换成因果的粘弹性模型，或在求和规则审计中去掉该经验损耗并单独处理无耗奇异谱权重。

## 功率交叉检查

100 Hz 以上，组合最细网格的 Boundary 93 通量与远场功率相对差的 95% 分位为 3.281%，最大值为 4.666%。约 22.8 Hz 以下，Boundary 93 有符号通量受小 `ka` 下大量入射/出射分量相减影响而出现错误负号；所以低频 `Rac` 采用远场方向图积分，不采用该通量。

## 空间离散收敛

在 50 Hz、1/4/8/12/15 kHz 六个锚点上，以“结构 L2 + 声学 refined1”组合网格为参考：

| 变体 | 复 Zmot RMS / max | 远场 Rac RMS / max |
|---|---:|---:|
| 基础网格 | 0.453% / 0.722% | 5.57% / 10.36% |
| 仅声学加密 | 0.333% / 0.689% | 0.856% / 2.014% |
| 仅结构加密 | 0.320% / 0.765% | 6.25% / 12.67% |

结构加密使 A0 从 0.03706180 变为 0.03707604 Ω·s，变化约 0.0384%；A∞ 在数字精度内不变。对端口阻抗，两类加密的影响都低于约 0.8%；对远场功率，声学网格是主要误差源，最细声学网格是必要的。

## 对原推导的最终判断

- FEM 结果支持“被动运动阻抗可分解为有用辐射与内部损耗”的基本物理链，并且定量表明本模型的谱预算几乎全部流向内部损耗。
- M2 在工程频窗中与静态端点高度一致，是有价值的数值支持；当前非因果恒定 loss-factor 外推使它不能作为严格定理验证。
- M0 的频率积分本身已达到约 1.5% 的后验稳定度，但 15 kHz 只覆盖 35.8% 的 A∞；必须先使用因果损耗模型，再扩展高频带宽或改用模态/虚轴方法，才能验证完整 M0 等式。
- 本次结果验证了固定离散的一个转换函数。生产模式在 3 kHz/8 kHz 切换网格或阶次后形成的拼接曲线，不能直接用作单一 Herglotz 函数的求和规则证据。

## 后续严格闭环的最短路径

1. 建立因果的频率依赖粘弹性材料模型，然后重做 M2 低频极限。
2. 对 M0 使用结构模态谱测度或虚轴 Poisson/Stieltjes 核验证；若继续实轴扫频，需要重新生成可解析 15 kHz 以上的声学网格，而不是盲目外推现有网格。
3. 用独立的结构耗散功率和声学吸收功率积分验证 `Rinternal`，使功率分解从“远场余量非负”升级为独立能量平衡。
