# 阶段 3B2：A/B reference 验证层

本文件只封板 `reference A open-back + B sealed` 的声学验证层，不是完整
Stage 3，也不是生产预测。驱动身份始终是 `reference planar piston`，全局
`v_z=+1 m/s`，采用 `exp(+iωt)`；`final_production_interface_ready=false`。
本阶段没有生产耦合、热黏性、port、PR、CLI 或旧 FEM solver。

## 1. 实际 1 m 与远场归一化

HK 使用 `hk_front + hk_rear` 的完整闭合球面，`mirror=false`，法向为球径向
outward normal，并调用同一个 closed-HK exact kernel。对 `R_eval` 取

```text
k R_eval >= 20,  R_eval > R_HK
p_ff_1m = p(R_eval) R_eval exp(+i k (R_eval - 1 m))
```

其中空间 outgoing 相位为 `exp(-ikR)/R`。`p_ff_1m` 是传播相位归一化后的远场
幅值，绝不能称为实际 1 m 压力。实际 1 m 字段保留为 `actual_pressure_1m`；
5–20 Hz 时 `kR(1 m)=0.0915–0.3661`，属于 near field，不参加偶极渐近斜率
门槛。

代表性 A/B、L1、20 Hz：

|---|---|---:|---:|---|---:|
|A|`0.000738+0.027265i`|59.684 dB / 88.449°|54.623 m / 20|`-0.010085+0.004677i`|51.889 dB / 155.123°|
|B|`0.028368+0.081306i`|69.670 dB / 70.766°|54.623 m / 20|`0.025723+0.074658i`|68.918 dB / 70.989°|

|---:|---:|---:|---:|---:|

独立线性拟合结果：5/10/20 Hz 远场斜率 `20.071 dB/decade`；5–80 Hz
斜率 `20.360 dB/decade`。实际 1 m 5/10/20 Hz 斜率仅 `0.771 dB/decade`，
因此没有把 near-field 数值错误套用到 dipole asymptote。

## 2. 层级收敛与功率

完整基准扫描为 A/B × L0/L1/L2 × 10/20/50/100 Hz，共 24 个 reference
solve。A 的压力 DOF 为 `1350/4786/18170`，B 为 `1290/4696/17864`。
L0 只作基线，不作最终收敛结论。

## 3. PML alpha 与临时外域变体

A/L1 的 explicit alpha `2/4/8/12` 在 20/50/100 Hz 共 12 点均
`discrete passive`。相对 alpha=4 的最大变化为 `0.141 dB/0.435°`，满足
`<0.2 dB/<2°`。target-nepers=8 不在本阶段重算；阶段 3B1 已记录当前 L1
低频离散 PML 出现负输入功率/负 HK 功率，仍为 unresolved/fail，只能 opt-in
诊断，不能恢复为默认模式。

A/L1 临时几何变体均在复制配置上生成并通过 topology/PML 审计；正式 configs
未改。相对 base、20/50/100 Hz 的最大幅值/相位变化如下：

|变体|最大 ΔdB|最大 Δphase|
|---|---:|---:|
|R0=0.35 m|0|0°|
